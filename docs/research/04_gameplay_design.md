# mushroomId 蘑菇图鉴 — 玩法设计报告（R4）

> 目标：把 fishId「出海 → 答 5 题 → 抽卡 → 入缸」的循环完整转译到蘑菇主题，同时利用蘑菇独有的生物学特性（生长周期、孢子、变色、发光、自溶）做出 fishId 做不到的差异化。
> 技术前提沿用 fishId：原生 HTML/CSS/JS，零依赖，localStorage，Canvas 动画，iframe 小游戏，postMessage 通信。凡未特别说明的模块，代码结构直接复用 fishId 同名模块（quiz.js / gacha.js / tank.js → garden.js / app.js / storage.js / sound.js）。

---

## 0. fishId 核心循环回顾（转译基准）

```
鱼缸首页 → 出海（扣每日次数）→ 2.5s 过场 → 答 5 题（看图认鱼 + 知识题，15s/题）
→ 结算抽卡（60/30/8/2，答错惩罚，≥3 错只给碎片，20/50 保底）
→ 稀有度横幅 + 语录 + 真实照片 → 放入鱼缸（10 槽）/ 分解精华
外围：碎片合成（5→1）、精华商店、每日宝箱、礼品码、每日任务、里程碑、分享、挑战好友、存档迁移
鱼缸：Canvas 分层、11 种行为、喂食/夜晚/摇一摇、状态机 swim/idle/scared/spin
小游戏：烧烤经营、猫抓鱼肉鸽、深海挂机、鱼鱼合并
```

fishId 的"物种"是**会动的动物**，鱼缸的乐趣来自运动；蘑菇是**几乎不动的生物**，乐趣必须改为来自**生长、变化、环境响应和触发式反应**。这是整份设计最核心的转译原则：**用「时间」替代「运动」**。

## 2. 主循环细化

### 2.1 进山采菌流程

```
菌菇园首页 → 点「进山」→ 选林地（4 选 1，2 秒内可跳过，默认上次）→ 扣 dailyForays.free
→ 2.5s 过场（竹篮、山雾、脚步声、天气特效）→ Quiz.prepare(biome, weather)
→ 答 5 题 → Gacha.startResult(wrong, correct, biome, weather) → 定植 / 分解
```

**林地类型（biome）是否值得做？——值得，但做"轻量版"。**
理由：(1) 它给玩家一个 fishId 没有的"选择"，让每次进山有目的性（想要松茸就去松林）；(2) 数据上只是给每种菌加一个 `biome` 字段并在选题/抽卡时过滤，实现成本 < 1 天；(3) 它是"图鉴按林地分组"的天然维度，让 200 种菌的图鉴页有结构。
不值得做的部分：真实地理定位、真实天气 API、季节锁（会让玩家在冬天无菌可采，与每日留存冲突）。

| biome | 名称 | 代表菌（示例） | 掉落权重规则 |
|---|---|---|---|
| `pine` | 🌲 松林/针叶林 | 松茸、松乳菇、见手青、美味牛肝菌、红菇 | 该林地菌 ×3 权重，其他林地菌 ×1 |
| `broadleaf` | 🌳 阔叶林/栎林 | 鸡油菌、青头菌、鹅膏属（毒蝇伞、死亡帽）、干巴菌 | 同上 |
| `deadwood` | 🪵 腐木区 | 木耳、平菇、灵芝、云芝、荧光小菇、蜜环菌、猴头菇 | 同上 |
| `meadow` | 🌾 草地/牧场 | 马勃、墨汁鬼伞、硬柄小皮伞（仙环）、双孢蘑菇、鸟巢菌 | 同上 |
| `special` | （不可选） | 竹荪（竹林）、冬虫夏草（高山草甸）、松露（地下） | 只在 `weather=rainAfter` 或传说保底时进入池子 |

**天气（weather）**：每日全服一致，无 API，用日期字符串 hash：

```js
// 同一天所有玩家看到同样天气 → 可社交（"今天雨后！快去采"）
function todayWeather(dateStr){           // 'YYYY-MM-DD'
  var h = 0; for (var i=0;i<dateStr.length;i++) h = (h*31 + dateStr.charCodeAt(i)) >>> 0;
  var r = h % 100;
  return r < 40 ? 'sunny' : r < 65 ? 'cloudy' : r < 85 ? 'rain' : 'rainAfter';   // 40/25/20/15
}
```

| weather | 图标 | 采菌效果 | 菌菇园效果 |
|---|---|---|---|
| `sunny` | ☀️ | 无 | 光斑更亮；`hygro` 菌合拢 |
| `cloudy` | ☁️ | 无 | 光线偏冷 |
| `rain` | 🌧 | 稀有 +5%（从普通挪） | 雨丝粒子；`splash` 菌弹蛋；`hygro` 菌张开；免费浇水 1 次/小时 |
| `rainAfter` | 🌈 | 稀有 +5%，珍稀 +2%（从普通挪）；`special` 林地菌入池 | 地面反光、雾气、蜗牛出没 |

天气只调概率 ≤7 个百分点，不破坏保底节奏；它的主要价值是**首页有变化**和**给玩家一个"今天要上线"的理由**（参考 Nameko 的天气影响稀有菇出现率，以及 Pokémon GO 的天气加成让特定类型刷新率上升、奖励 +25%）。

### 2.2 题型设计

fishId 是 3 种题型（name_from_image / trivia / cold_fact）。蘑菇因为有"可食性"和"易混淆"两个强知识维度，扩到 **6 种题型**：

| type | 名称 | 题干模板 | 选项 | 难度 | 目标数量（200 种） |
|---|---|---|---|---|---|
| `name_from_image` | 看图认菌 | 「这是哪种菌？」 | 4 个菌名（中文 + 英文/拉丁属名小字，复用 `.opt-en`） | 1-3 | 200 |
| `edibility` | 食性判断 | 「〔菌名〕的食性是？」（题干**给出菌名**，不让玩家凭图判断能否吃） | 可食 / 条件可食（需彻底煮熟） / 药用不宜食 / 有毒 | 2 | 200 |
| `lookalike` | 易混淆对比 | 「〔菌名〕最容易与下列哪种毒菌混淆？」或「区分鸡油菌和毒黄鹅膏，最可靠的特征是？」 | 4 个菌名 / 4 个特征描述 | 3 | 120（只覆盖有 lookalikes 的物种） |
| `feature` | 特征题 | 孢子印颜色 / 菌褶还是菌管 / 有无菌环菌托 / 长在什么基质上 | 4 选 1 | 2-3 | 200 |
| `trivia` | 趣味知识 | 同 fishId trivia | 4 选 1 | 4 | 350 |
| `cold_fact` | 冷知识 | 同 fishId cold_fact（含急救与中毒机理题，见 7.3） | 4 选 1 | 5 | 180 |

题库目标：**约 1250 道**（fishId 是 1087 道 / 270 种；蘑菇 200 种但题型更多）。

**所有题目均显示真实照片**（沿用 fishId 规则）。`edibility` 题在照片上叠加**该菌名字**——刻意避免"看图猜能不能吃"这种会培养危险直觉的题型。

**选题规则（按用户难度设置）**：

| 设置 | 看图认菌 | 其他题槽（5 − imageCount 道） |
|---|---|---|
| 🍄 菌子萌新 | imageCount 道，d1 | `edibility` d2 优先，其余 `trivia` d4 |
| 🧺 采菌爱好者 | imageCount 道，d2 | `feature` d2-3 + `trivia` d4 各半 |
| 🔬 菌物学家 | imageCount 道，d3 | `lookalike` d3 至少 1 道 + `cold_fact` d5 |

`lookalike` 题的选项生成：正确答案取 `fish.lookalikes[0]`，干扰项从**同 biome、不同科**的菌中取，保证不出现两个都"合理"的答案。

**每题 15 秒**、超时算错、答错展示 habitat + fact + **食性标签**——全部沿用 quiz.js。

### 2.3 抽卡与稀有度

**结论：保留 60 / 30 / 8 / 2，保留 20 / 50 保底，保留"答错惩罚"和"≥3 错只给孢子"。** 理由：fishId 数值已验证，且蘑菇玩家与鱼玩家的会话节奏一致（每局 5 题约 90 秒）。改动只在两处：

1. **天气修正**（2.1 表）：`rain` 稀有 +5，`rainAfter` 稀有 +5 珍稀 +2，均从普通扣除。
2. **林地过滤**：`pickMushroom(rarity, biome)` 先在该稀有度内按 biome 权重（本林地 ×3）抽。若该稀有度在此林地没有菌，退回全池。

概率表（正常 / 惩罚 / 雨后正常）：

| 稀有度 | 正常 | 答错 1-2 题 | 雨后（rainAfter） |
|---|---|---|---|
| 普通 | 60% | 75% | 53% |
| 稀有 | 30% | 20% | 35% |
| 珍稀 | 8% | 4% | 10% |
| 传说 | 2% | 1% | 2% |

**满分奖励**：5 题全对额外 +1 个当次稀有度的孢子（fishId 只有横幅，这里给一点实物，鼓励认真答题）。

**图鉴规模建议：200 种**（普通 80 / 稀有 75 / 珍稀 32 / 传说 13）。少于 fishId 的 270 是因为蘑菇的真实照片筛选更难（很多物种 Commons 只有标本照或采后照），且 200 已足够支撑 6 个月留存。

传说 13 种候选：松茸、松露（黑孢块菌）、冬虫夏草、竹荪、荧光小菇、鬼笔（红笼头菌）、羊肚菌、猴头菇、死亡帽（毒鹅膏，"剧毒传说"）、毁灭天使（鳞柄白鹅膏）、火焰茸（剧毒）、干巴菌、鸡㙡。

### 2.4 毒菌在收集系统里的定位

**原则：毒菌是图鉴的正式成员、视觉上更炫、稀有度分布与可食菌一致，但从卡片到分享的每一处都带不可移除的「仅科普·切勿采食」标识。**

食性字段（`edibility`）与标签：

| 值 | 标签 | 色 | 卡片处理 |
|---|---|---|---|
| `edible` | 🍽 可食 | 绿 #7EC8A0 | 脚注："野生菌请通过正规渠道购买，本游戏不提供采食依据" |
| `conditional` | 🔥 条件可食 | 橙 #F5A623 | 脚注："需彻底煮熟，误食可致幻/中毒"（见手青类） |
| `medicinal` | 💊 药用 | 青 #14A098 | 脚注："药用不等于可食" |
| `toxic` | ⚠️ 有毒 | 红 #EF7676 | 卡片左上角红色斜带「有毒·仅科普」 |
| `deadly` | ☠️ 剧毒 | 深红 #B0203A + 黑边 | 斜带「剧毒·致命」+ 卡片背景加暗红脉络纹理 |
| `unknown` | ❓ 食性不明 | 灰 | 脚注："食性不明视同有毒" |

**毒菌的"炫"从哪来**：
- `deadly` 卡片有专属结算音效（低沉的钟声 + 心跳）和专属横幅文案「☠️ 你遇到了致命的它——记住它的样子」；
- 死亡帽、毁灭天使、火焰茸放在**传说档**；毒蝇伞（最上镜的红伞白点）放**珍稀档**；
- 图鉴页顶部新增筛选「☠️ 毒菌图鉴」，集齐所有 `toxic + deadly` 有独立成就「毒菌鉴定官」；
- 毒菌在菌菇园里**可以定植**——它们本来就是森林的一部分。毒蝇伞在园里，是最好的"记住它长什么样"的方式。

**毒菌不惩罚**：抽到毒菌不扣任何东西。让玩家怕毒菌只会让他们不学。

## 3. 菌菇园（替代鱼缸）的 Canvas 设计

### 3.1 视角：侧视森林剖面（推荐）

```
┌──────────────────────────────────────────────┐  ← 顶部：天空/树冠缝隙（天气在这里表现）
│  远景树干剪影（3-4 根，视差 0.2）+ 斜射光柱      │
│  中景树干（2 根，视差 0.5）+ 悬浮孢子/花粉粒子   │
│      🍄  🍄        ┌────────────┐     🍄       │  ← 林地槽 L1-L2（左） / R1-R2（右）
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│  腐  木  🍄🍄🍄🍄│▒▒▒▒▒▒▒▒▒▒▒ │  ← 腐木槽 W1-W4（木上）
│  苔藓/落叶地面      └────────────┘  🍄   🍄     │  ← 特殊槽 S1（腐木侧面：架状菌）S2（地面前景：寄生/地下菌）
│  前景落叶 / 蜗牛 / 萤火虫（夜）/ 雨丝（雨）       │
└──────────────────────────────────────────────┘
```

- 选侧视剖面而非俯视：蘑菇的识别特征（菌盖、菌柄、菌环、菌裙）都在侧面，俯视只能看见一个圆。
- 腐木居中占宽 40%，高 12%，这是"舞台"；它给木生菌一个合理的落脚点，也自然把画面分成左右两块林地。
- 参考 Stardew Valley 的 Mushroom Log（腐木上长菇）与农场洞穴的固定 6 个菇箱：固定槽位而非自由摆放，实现成本低、布局永远好看。

**备选**：俯视林地（适合"仙环"这类地面图案，但牺牲物种辨识度）；腐木特写（画面精致，但容不下草地菌、寄生菌和地下菌）。

### 3.2 层次与氛围（对标 tank.js 的分层）

```
天空缝隙渐变 → 远景树干 → 光柱（sunny 强 / cloudy 弱 / night 关）→ 中景树干
→ 悬浮孢子粒子（对标浮游生物）→ 地面（苔藓渐变 + 落叶贴图）→ 腐木
→ 蘑菇层（按 y 排序，靠前的后画）→ 前景落叶 → 天气粒子（雨丝 / 雾）→ 夜晚荧光层（萤火虫 + glow 光晕）
```

**昼夜**：沿用 fishId，19:00–6:00 自动夜晚（skyBlend=1），长按 0.8s 手动切换（manualOverride）。夜晚 = **荧光夜**：整体色调 #0B1B2B → #12293D；20 只萤火虫（缓慢布朗运动 + 呼吸闪烁 2-4s 周期）；`glow` 行为菌在菌盖/菌褶位置叠加 `radialGradient` 绿光（#9CFF7A，alpha 0.55，半径 = size × 40px，呼吸周期 3s）。

**雨天**：`weather=rain` 时画雨丝（120 条 1px 线段，长 12-20px，速度 600px/s，透明 0.35）；地面苔藓亮度 +10%；`splash` 菌每 8-15s 触发一次弹蛋。

### 3.3 生长周期状态机（核心长线留存机制）

真实菌类周期：孢子萌发 → 菌丝 → 菌丝结 → 原基（针头）→ 24-48h 内成形 → 3-5 天成熟（参考 GroCycle / BootstrapBee 时间线）。游戏里压缩为**四段 + 一个可选段**，用真实时间推进：

```
                浇水 +8%/次                    每 24h（或收获后）
spore ──(定植即跳过)──▶ pin ──(30 min)──▶ young ──(3 h)──▶ mature ──(24 h)──▶ sporulate
                                                                 ▲                 │
                                                                 └── 点击收孢子 ────┘
```

| stage | 显示 | 时长（成熟度 0→1） | 备注 |
|---|---|---|---|
| `pin` 菌蕾 | Q 版图缩放 0.35，从地面/木上"顶"出（y 偏移 +40% → 0） | 30 分钟 | 定植后立刻看到东西 |
| `young` 幼菌 | 缩放 0.35 → 1.0，线性；菌盖颜色饱和度 0.7 → 1.0 | 3 小时 | 浇水 1 次 = +8% 进度（≈14 分钟） |
| `mature` 成熟 | 完整 Q 版图，行为系统生效 | 24 小时后可释放孢子 | 这是"正常展示态" |
| `sporulate` 孢子成熟 | 菌盖上方出现细微孢子雨粒子 + 金色小图标 | 等待玩家点击 | 点击 → +1 该稀有度孢子（`fragments`）→ 回到 `mature`，计时重置 |

**为什么值得做**：这是 Nameko（なめこ栽培キット）的核心留存机制——放置、回来收获、再放置；也是 Pokémon GO "candy"的等价物——每天回来能从已有收藏里"挤"出资源。fishId 现在的鱼缸是纯观赏，没有产出；菌菇园的"每 24h 产 1 孢子 × 10 槽 = 每天 10 个孢子（≈2 次合成）"给了打开首页的硬理由。

**数值防滥用**：
- 每槽每 24h 最多 1 孢子，不叠加（离线 3 天回来只有 1 个待收，避免"离线越久越赚"）；
- 浇水每小时 10 次，只加速 `young`，对 `mature→sporulate` 计时无效；
- 传说菌的孢子是传说孢子（5 个合成 1 传说，等于 5 天 1 只传说槽 = 每 5 天一张传说卡）——这个产出速度是"有诚意但不破坏抽卡价值"的平衡点，可通过把传说槽产出改成 48h 微调。

**离线表现**：进入首页时按 `Date.now() - lastSeen` 一次性推进所有槽的 stage（纯函数 `advanceStage(slot, elapsedMs)`），无需后台计时。

**MVP 降级**：第一版可只做 `pin → mature`（30 分钟成形）+ 每日一次全园「孢子收集」按钮（等价于 10 个槽同时 sporulate），状态机字段照旧预留。

## 4. 蘑菇「行为」系统（对标 fishId 11 种鱼行为）

fishId 的行为是"怎么游"；蘑菇的行为是"长什么形 + 对什么起反应"。每个行为定义三件事：**静态形态修饰**（怎么画）、**环境响应**（对天气/昼夜/风的反应）、**点击反应**（玩家点它发生什么）。

| id | 名称 | 代表物种（200 种中估算数量） | 静态形态 | 环境响应 | 点击反应 | 动画要点 |
|---|---|---|---|---|---|---|
| `puff` | 喷孢 | 马勃、大秃马勃、尖顶地星、脱皮马勃（≈10） | 球形，无柄 | 起风时自动喷 | 顶部喷出 40-80 颗棕色孢子粒子（2px，初速 80-140px/s，向上 60° 扇形，重力 40px/s²，寿命 1.5s）；本体压扁 scaleY 0.85 再回弹（120ms） | 每次点击冷却 600ms；连点 5 次出「孢子云」大特效 |
| `stink` | 腐臭引蝇 | 白鬼笔、红笼头菌、海星菌、尖鬼笔（≈6） | 顶端深色黏液区 | 无 | 苍蝇短暂惊飞再回归 | 常驻 3-5 只苍蝇（3px 黑点 + 抖动翅膀线）绕菌顶做 Lissajous 轨迹（半径 18px，周期 1.2s）；夜晚数量减半 |
| `glow` | 荧光 | 荧光小菇、Jack-o'-lantern（奥氏蜜环菌属 Omphalotus）、苦牡蛎菇、蜜环菌菌丝（≈8） | 白天普通 | **荧光夜**时菌盖/菌褶发绿光（#9CFF7A 径向渐变，alpha 0.55，呼吸 3s）；晴天白天不发光 | 白天点：无特殊（提示"等夜晚再来"）；夜晚点：光晕爆发到 2× 持续 0.8s | 参考真实：Mycena chlorophos 在雨季夜间成片发光；只有夜间发光才是"正确的科普" |

## 7. 安全与教育定位

### 7.1 六条硬规则（写进 CLAUDE.md 开发约定）

1. **不做"看图判断能不能吃"的任何题、任何小游戏**。所有食性判断题干必须给出菌名（"〔见手青〕的食性是？"），毒菌快筛卡片也显示菌名。玩家学的是"这个名字的菌是什么食性"，不是"长这样的菌能吃"。
2. **每张卡片、每个分享图、每个详情页底部固定安全脚注**，字号 11px，灰色，不抢眼但永远在。
3. **抽到 `edible` 菌时的语录禁止出现"好吃""快去采"**；语气是蘑菇自我介绍，例如鸡油菌："我有杏子香，但山里长得像我的有好几位。"
4. **首次教程 6 张卡里第 3 张是安全卡**（放在稀有度表之前）：「这是一款图鉴游戏，不是鉴定工具。野生菌 900 多种可食、200 多种有毒，很多长得一模一样。」并列出云南疾控每年的三句话：不采、不买、不吃不认识的野生菌。
5. **菌名与照片必须来自可靠来源并经事实核查**（沿用 fishId 的 60-agent 核查流程），毒菌尤其如此——把毒菌标成可食是本产品唯一不可接受的 bug 等级。
6. **不用"红伞伞白杆杆"来指代一切毒菌**：那首顺口溜暗示"看颜色就能判断"，恰好是疾控反复辟谣的误区。游戏里可以玩这个梗（TANGBANBAN 礼品码、成就名），但玩梗处必带一句"颜色不能判断毒性"。

### 7.2 有趣而不说教的做法

- **让蘑菇自己说**：毒菌语录第一人称、傲娇。死亡帽："我很好看，我知道。也很好吃，据说——只是没人活着回来夸我。"毒蝇伞："童话里的红伞白点是我。童话没说的是后半句。"
- **蜗牛绕开剧毒菌**（3.5 节）：不说一句话的科普。
- **火锅店的"看小人"投诉**（6 节）：把"见手青必须炒熟"做成经营惩罚，玩家会记住。
- **毒菌快筛的结算文案**：即便 100% 正确也显示「你认出了它们——所以你更知道：真的山里，别采。」
- **急救知识做成冷知识题而非弹窗**：例如「误食野生菌出现症状，正确的第一步是？→ 立刻催吐并尽快就医，带上剩余菌样本」；「野生菌中毒的"假愈期"指什么？→ 部分剧毒鹅膏中毒者症状缓解后 1-2 天出现肝损伤，不能因好转而停止就医」。

### 7.3 是否加入「毒菌急救知识」——加，作为常驻卡片 + 题库

「我的」页新增 **🚑 安全卡**（一屏，可分享）：

```
如果有人误食了不认识的野生菌：
1️⃣ 立刻催吐（意识清醒者）：喝温盐水，刺激咽喉
2️⃣ 保留样本：剩余的菌、呕吐物，方便医生鉴定
3️⃣ 马上就医 / 拨打 120，告诉医生"吃了野生菌"，同食者一起去
⚠️ 症状缓解 ≠ 痊愈，剧毒鹅膏有"假愈期"
—— 内容依据云南省疾控局 / 卫健委公开科普
```

此卡在收集到 25 种时自动弹出一次（里程碑「采菌爱好者」附带），之后常驻。`cold_fact` 题库中预留 ≥15 道急救与中毒机理题（鹅膏毒素、鹿花菌素、见手青致幻、"催吐不适用于昏迷者"等）。

## 8. 差异化亮点 Top 5 与 MVP 范围

### 8.1 Top 5（相对 fishId 和市面蘑菇游戏）

1. **真实时间生长 + 每日孢子产出**：鱼缸是观赏，菌菇园是"会产出的收藏"。Nameko 有生长没有科普图鉴，Stardew 有采集没有养成，fishId 有图鉴没有产出——三者的交集是空白。
2. **12 种基于真实生物学的触发行为**：触摸变蓝（见手青）、夜间荧光（荧光小菇）、自溶滴墨（鬼伞）、湿度开合（气压计地星）、雨滴溅蛋（鸟巢菌）、晨开午合的竹荪网裙——每一个都是"哦原来真的会这样"的科普瞬间，也是分享素材。
3. **毒菌是最炫的卡**：剧毒传说卡、毒菌图鉴、毒菌鉴定官成就、蜗牛绕行——把"危险"转化为收集欲，而不是回避。
4. **全服同步天气 + 林地选择**：给每天上线一个理由（"今天雨后！"），给每次进山一个目的（"去松林找松茸"），且实现成本极低（日期 hash + 权重过滤）。
5. **安全教育内建于玩法而非弹窗**：毒菌快筛、火锅店"看小人"惩罚、题干强制给菌名、分享图固定水印——在中国社交平台上"捡菌子"是现象级话题（人民日报、界面、央广都在 2024-2025 年做过见手青报道），一款"好玩且负责任"的蘑菇图鉴有清晰的传播叙事。

### 8.2 MVP（第一版，约 4-5 周工程量）

**做：**
- 120 种菌（普通 50 / 稀有 45 / 珍稀 18 / 传说 7）+ 约 700 道题（`name_from_image` 120、`edibility` 120、`feature` 120、`trivia` 240、`cold_fact` 100；`lookalike` 先做 40 道）
- 进山流程：4 林地选择 + 日期 hash 天气（只影响概率与首页氛围）
- 答题 / 抽卡 / 保底 / 孢子合成 / 腐殖质菌种库：直接复用 fishId 代码
- 菌菇园 Canvas：侧视剖面、10 槽、昼夜（荧光夜）、雨天粒子、浇水、起风（摇一摇）、点击空白惊虫
- 生长：`pin → mature`（30 分钟）+ 每日一次「收集孢子」按钮（简化版 sporulate）
- 行为：先做 6 种最省力且最亮眼的——`glow` / `bruise` / `puff` / `jelly` / `cluster` / `default`（含 `spots`/`wrinkle` 子标记）；其余 `ink / stink / hygro / splash / coral / veil / shelf / parasite` 数据字段预留，先按 `default` 绘制
- 外围：每日任务（4 项）、每日菌篮、礼品码、6 个里程碑、分享 4 种（含固定水印）、挑战好友、存档迁移（`.spore`）
- 安全：教程安全卡、安全急救卡、脚注、食性标签体系
- 小游戏：合并（换皮）+ 栽培挂机（换皮）

**砍（V2 再做）：**
- 完整 4 段生长状态机与每槽独立 24h 孢子计时（MVP 用全园每日按钮）
- 剩余 8 种行为的动画
- 蜗牛互动、腐木年轮
- 野生菌火锅店、松鼠采菌、毒菌快筛、孢子印实验室（V2 按 6 节优先级依次上）
- 200 种全量与 `lookalike` 全覆盖
- 国际化（沿用 fishId 的 `fish_lang` + `T()` 方案，V2 加英文）

**风险与对策：**
- 真实照片供给：蘑菇 Commons 图片中"活体 + 自然基质 + 主体清晰"比例低于鱼；先按 120 种筛选，`photo_picker.html` 直接复用；剧毒菌尤其要多备候选。
- Q 版立绘一致性：蘑菇形态差异大（球/伞/架/珊瑚/网裙），需要在美术规范里定 5 个基础轮廓模板，避免 120 张风格漂移。
- 生长机制导致首页"空"：新玩家前 30 分钟只有菌蕾。对策：教程赠送 2 个已成熟普通菌 + 1 个 `glow` 幼菌（第一晚就能看到荧光）。
