## 三条产品红线

1. 不做用户拍照识别（MVP / V2）。
2. 永远不输出「可食」结论；食性只作为「资料记载类别」的图鉴知识。
3. 不做「看图判断能不能吃」的任何题或小游戏。

本项目所有「食用 / 有毒」信息仅转述公开资料，不能用于野外鉴定，更不能作为采食依据。野生蘑菇不采、不买、不吃。
